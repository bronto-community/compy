# compy v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First working version of compy — a Go CLI + launchd-supervised local OTel Collector + minimal localhost web UI + macOS tray.

**Architecture:** One Go binary, pure control plane over a state directory. launchd supervises the collector (no compy daemon). Config = base.yaml + one fragment per enabled backend, merged by the collector itself with the `confmap.enableMergeAppendOption` feature gate (verified: lists append). Apply = validate with the selected distro binary → snapshot last-good → rewrite plist → kickstart → probe.

**Tech Stack:** Go ≥1.24, stdlib only, except `fyne.io/systray` (tray, Task 8). No cobra (stdlib arg dispatch), no yaml lib (we only write YAML via text/template; the collector parses it).

**Spec:** `docs/superpowers/specs/2026-08-24-local-collector-design.md` — read it first.

## Global Constraints

- Module path: `github.com/bronto-community/compy` (placeholder org; one sed to change).
- Go `1.24` floor in go.mod. Toolchain on machine: go1.27.0 darwin/arm64.
- Dependencies: stdlib only; sole exception `fyne.io/systray` in Task 8.
- Default ports: gRPC `14317`, HTTP `14318`, always bound to `127.0.0.1`.
- Feature gate `confmap.enableMergeAppendOption` is ALWAYS passed to the collector (validate and run).
- State dir: `$COMPY_HOME` if set, else `~/Library/Application Support/compy` (darwin) / `${XDG_DATA_HOME:-~/.local/share}/compy` (other). Every test sets `COMPY_HOME` to `t.TempDir()`.
- launchd label: `io.bronto.compy.collector`.
- Backend names: `^[a-z0-9][a-z0-9-]*$`, max 64 chars. Reject anything else (they become file names).
- All state-file writes atomic: write `<file>.tmp` in same dir, `os.Rename`.
- Every task: `gofmt`-clean, `go vet ./...` clean, `go test ./...` green before commit. Commit per task with message given in the task.
- No file may import a package from a HIGHER-numbered task.

```go
package config

const MergeGate = "confmap.enableMergeAppendOption"

func EnsureBase(dir string, s state.Settings) (string, error) // writes config/base.yaml ONLY if missing; returns its path
func BackendPath(dir, name string) string                     // dir/config/backends/<name>.yaml
func WriteBackend(dir, name string, yaml []byte) error        // rejects invalid names
func ListBackends(dir string) ([]string, error)               // sorted names (from *.yaml files)
func DeleteBackend(dir, name string) error
func Preset(kind, name, endpoint, apiKey string) ([]byte, error) // kind: "otlp-grpc"|"otlp-http"|"bronto"|"debug"; name = backend name, scopes the exporter component ID (<type>/<name>) so same-kind backends don't collide on merge
func Args(dir string, s state.Settings) ([]string, error)     // full collector arg list (see below)
func SnapshotLastGood(dir string) error                       // copies config/ tree + settings.json into last-good/
func RestoreLastGood(dir string) error                        // copies back; error if no snapshot
```

`Args` returns, in managed mode:
`["--config", <base>, "--config", <frag per enabled backend, sorted>, "--feature-gates=" + MergeGate]`
— error if an enabled backend's fragment file is missing. In `RawMode`:
`["--config", dir + "/config/custom.yaml", "--feature-gates=" + MergeGate]`.

**Base template** (`text/template`, ports from Settings):

```yaml
receivers:
  otlp:
    protocols:
      grpc:
        endpoint: 127.0.0.1:{{.GRPCPort}}
      http:
        endpoint: 127.0.0.1:{{.HTTPPort}}
exporters:
  nop:
processors:
  batch:
service:
  pipelines:
    traces:
      receivers: [otlp]
      processors: [batch]
      exporters: [nop]
    metrics:
      receivers: [otlp]
      processors: [batch]
      exporters: [nop]
    logs:
      receivers: [otlp]
      processors: [batch]
      exporters: [nop]
```

(`nop` stays permanently so zero-backends is valid — spec R1. Ports are
written at creation only; settings stay authoritative for probe/env.
`# ponytail: base.yaml not regenerated on port change; edit base.yaml + settings together or delete base.yaml to regenerate`.)

**Presets** — each fragment adds its exporter to all three pipelines:

```yaml

exporters:
  otlp/{{.Name}}:
    endpoint: {{.Endpoint}}
{{- if .APIKey}}
    headers:
      x-api-key: {{.APIKey}}
{{- end}}
service:
  pipelines:
    traces:
      exporters: [otlp/{{.Name}}]
    metrics:
      exporters: [otlp/{{.Name}}]
    logs:
      exporters: [otlp/{{.Name}}]
```

`otlp-http`: same with `otlphttp/{{.Name}}`. `debug`: `debug/{{.Name}}` exporter with `verbosity: normal`, no endpoint/key. **bronto**: BEFORE writing this preset, invoke the `bronto` skill (Skill tool, skill name `bronto`) and use its documented OTLP ingestion endpoint and auth header names — do not guess them; if the skill is unavailable, use `otlphttp` with `endpoint: {{.Endpoint}}` and header `x-bronto-api-key: {{.APIKey}}` and leave a `// ponytail: verify bronto header against docs` comment.

```go
package launchd

const Label = "io.bronto.compy.collector"

// Exec is the launchctl runner, a package var so tests can stub it.
// Default: exec.Command("launchctl", args...).CombinedOutput()
var Exec func(args ...string) ([]byte, error)

func PlistPath() (string, error)                    // ~/Library/LaunchAgents/<Label>.plist
```

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>{{.Label}}</string>
  <key>ProgramArguments</key><array>
    {{range .Argv}}<string>{{.}}</string>
    {{end}}</array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardErrorPath</key><string>{{.LogPath}}</string>
  <key>StandardOutPath</key><string>{{.LogPath}}</string>
</dict></plist>
```

```go
package app

type App struct {
    Dir string // state dir
}

func New() (*App, error) // state.Dir + EnsureBase with loaded settings

func (a *App) SelectedDistro() (state.Distro, error) // error mentions "compy distro add" if none
func (a *App) Apply() error
// 1. args := config.Args(a.Dir, settings)
// 2. collector.Validate(distro.Path, args) — on error return it UNCHANGED (carries collector output)
// 3. if launchd.Running() → config.SnapshotLastGood(a.Dir)
// 4. launchd.Install(distro.Path, args, logPath) ; launchd.Kickstart()
// 5. collector.Probe(settings.GRPCPort, 5*time.Second) — on failure return error wrapping

func (a *App) Status() (Status, error)

type Status struct {
    Running  bool           `json:"running"`
    Distro   string         `json:"distro"`
    GRPCPort int            `json:"grpc_port"`
    HTTPPort int            `json:"http_port"`
    Enabled  []string       `json:"enabled"`
    RawMode  bool           `json:"raw_mode"`
}
```

```

compy apply | rollback | validate
compy backend list
compy backend add <name> --kind otlp-grpc|otlp-http|bronto|debug [--endpoint URL] [--api-key KEY]
compy backend remove|enable|disable <name>     # enable/disable edit settings.Enabled then Apply
compy backend edit <name>                      # $EDITOR on fragment, then Apply if enabled
compy distro list
compy distro add <name> <path>                 # path must exist+be executable; then `use` it if first
compy distro use <name>                        # validate against new binary via Apply
compy service install|uninstall|status
compy env [--shell sh|fish|pwsh]
compy run -- <cmd...>                          # exit with child's code
compy env set-os | unset-os                    # envvars.SetOS/UnsetOS + settings.OSEnv
compy raw on|off                               # settings.RawMode toggle, then Apply
compy raw edit                                 # $EDITOR on config/custom.yaml, then Apply if raw mode on
compy ui [--port 0]                            # webui.Serve on 127.0.0.1, print URL, exec `open <url>` on darwin
```
