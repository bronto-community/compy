### Task 1: contract additions + CLI parity

**Files:** internal/cfgstore (+test), internal/app (+test), internal/webui (routes/handlers/tests), api/openapi.json, cmd/compy/main.go

**Additions (each: app method + closure + route + openapi + handler tests + CLI):**
- `PUT /api/distros/{name}` {"path"} → app.SetDistroPath(name, path): path must exist+be executable; overriding a shipped definition returns the same "warning" field as AddDistro. CLI: `compy distro set-path <name> <path>`.
- `DELETE /api/distros/{name}` → app.RemoveDistro(name): removes a USER registry entry (a definition override reverts to the definition — say so in the response {"reverted":true|false}); deleting a pure definition name with no user entry = 400; deleting the SELECTED distro = 400 with a clear error. CLI: `compy distro remove <name>`.
- `GET /api/log?lines=N` (default 50, cap 2000, 400 on junk): Log closure becomes func(n int) (string, error); CLI `compy log [--lines N]` (new, tiny — parity).
- `POST /api/configs/{name}/sets/{set}/rename` {"to"} → app.RenameSet via cfgstore.RenameSet (validates config name; errors if `to` exists or set missing; renaming the active set follows it). CLI: `compy sets rename <config> <from> <to>`.
- openapi: declare the {"ok":true} 200 bodies on action routes while in there (deferred item).
- [ ] TDD throughout; commit `feat: P3 contract additions (distro edit/remove, log lines, set rename)`.

### Task 4: Configuration editor view

**Files:** internal/webui/static/{app.js,app.css,index.html} (editor view), no Go changes expected

- Route #/configs/<name>. Three sections:
  1. Properties card: name (read-only in v1 — rename is not in the API; omit pretending), remote URL (editable → PUT meta; empty = local), default distro (select from /api/distros → PUT meta), provenance/modified line; for remote: Sync/Resync buttons with modified-awareness (Sync hidden when modified, "Discard local edits & re-sync" shown with confirm).

Save = PUT yaml; then POST validate and show result inline (ok chip / verbatim error panel). A separate "Validate" button runs validate without saving? (No API for validating unsaved text — validate AFTER save only; label the button "Save & validate".)
